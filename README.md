# ArtConnect 

ArtConnect is a MERN-based artist portfolio and commission platform that connects artists with clients.

## About the Project

ArtConnect allows artists to showcase their artwork through personalized profiles and allows clients to explore artists, request commissions, and provide reviews after completed commissions.

## Features

- User registration and login
- Role-based access for Artists and Clients
- Artist profile creation and management
- Artwork upload and management
- Browse and explore artists
- Commission request system
- Accept/Reject commission requests
- Commission status tracking
- Client and Artist dashboards
- Artist reviews and ratings
- Cloudinary image upload
- JWT-based authentication
